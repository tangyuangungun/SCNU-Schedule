## 1.4.0 安全更新

1. 账号和密码改用 Android Keystore 中的 AES-GCM 密钥加密保存。
2. 从旧版本升级时自动迁移并删除旧的明文凭据。
3. 用户可以取消保存登录信息；未保存时密码仅保留在当前应用进程内。
4. 首次启动增加隐私与权限说明及用户同意。
5. 同步完成或失败后清除同步引擎内存中的密码。
6. WebView 禁用本地文件和内容访问，并开启 Safe Browsing。
7. 使用 4096 位 RSA 正式发布密钥和 APK Signature Scheme v2/v3 签名。

## 安装说明

- 当前版本使用正式发布签名。
- 已安装旧测试签名版本的用户，需要先卸载旧版，再安装本版本。
- 后续相同签名版本可以直接覆盖升级。
- 安装前请核对 SHA-256 和签名证书 SHA-256。
