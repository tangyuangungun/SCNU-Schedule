# 华师课表 Android 版

- 版本：1.3.0
- 最低系统：Android 8.0（API 26）
- 目标系统：Android 15（API 35）
- SHA-256：`64D267E8869DD901310F1EBECDCA30F768ADB5C0861DB5312D8335835D265EBE`

## 本次修复
1. 修复桌面小组件“载入窗口小部件时出现问题”。
   - 小尺寸和大尺寸布局中的普通 `View` 分隔线改为 RemoteViews 支持的 `TextView`。
   - 中等尺寸“本周概览”现在同时显示课程数量和第一门课程简称。
2. 登录确认页改为原生触摸点击。
   - 不再只依赖 JavaScript `click()`，避免学校页面拒绝脚本点击。
   - 自动查找“确定登录”等按钮的位置，并向 WebView 发送真实的按下、抬起事件。
   - 支持在页面和同源 iframe 中查找按钮。
3. 左右滑动切换日程、周程、更多时加入淡出和淡入动画。
4. 周程时间栏改为对应节次的开始和结束时间，例如：
   - 第 1 节：08:30 / 09:10
   - 第 5 节：14:00 / 14:40
   - 第 11 节：20:40 / 21:30
5. 简化课表顶部信息卡，移除与周次导航重复的“第几周、日期范围”。

## 已有功能
- 统一身份认证登录和 WebView 自动抓取课程表。
- 日程、周程、更多三个底部入口。
- 一周网格课表、周次与日期匹配。
- 每周/每月自动更新与手动更新。
- 手机本地日历导入。
- 消息提醒和闹钟提醒。
- 今日课程、本周概览、一周课表三种桌面小组件。
- 浅色/深色蓝白主题。
- Android 15 状态栏安全区适配。
